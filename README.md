# Traffic Light Digital Twin

## Project Description
This project simulates a real-world traffic light using
Python object oriented programming (OOP).

The digital twin tracks the traffic light's color, status,
location, waiting cars, and completed cycles.

## Attributes
- location
- color
- status
- cars_waiting
- cycles_completed

## Methods
- turn_green()
- turn_yellow()
- turn_red()
- add_car()
- let_cars_go()
- turn_off()
- turn_on()
- display_status()

## How to Run
1. Install Python.
2. Open the project in Visual Studio Code.
3. Open the terminal.
4. Run: python traffic_light.py

## Example Behavior
The traffic light changes from red to green, yellow,
and back to red. It tracks waiting cars and completed
cycles. It can also be turned off and back on.
